# Common 通用模块 API 说明

## 模块概述
通用工具模块，包含附件上传等通用功能。

## API 文件与页面对应关系

| API 文件路径 | 对应页面路径 | 页面名称 | 已对接 | 说明 |
|-------------|-------------|---------|-------|------|
| `common/attachment/index.js` | 全局通用 | 附件上传 | ❌ | 附件的上传、下载、删除，所有模块通用 |

## 接口路径前缀
所有Common模块接口前缀：`/admin-api/common`

## 通用接口说明
- 附件上传支持多种文件格式
- 时间字段（createTime）为毫秒时间戳，前端需格式化
